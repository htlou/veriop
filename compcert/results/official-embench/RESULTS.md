# Baseline and frozen C1: official Embench harness results

**Reference correction:** The speed numbers below use a local reference and
do not satisfy the requested published-reference Embench speed metric.
Published-reference speed scores have not been established. The published
Cortex-M4 size scores below do use the official reference data.

C1 shows no stable official speed-score gain. Every number below is copied from the unmodified upstream Embench 1.0 script output, at its printed precision. Larger speed is better; smaller size is better.

Speed reference: original CompCert on this same CPU with CPU_MHZ=10000, generated by upstream `--baseline-output`. This is the documented local-reference mode, not a Cortex-M4-normalized speed claim. All 19 programs are included.

The size scores round to the same value; this does not assert identical byte counts. Size uses the official dummy-library convention, with two documented CompCert dummy math symbols. Cross-architecture size differences also reflect compiler/runtime/section settings.

Native `time -p` has 10 ms resolution. The 50–60 ms nbody case changes its relative score from 1.00 to 0.83 with one timer step. No temporal confidence interval or sub-percent improvement is established by these runs. The displayed geometric SD is spread across programs, not measurement uncertainty.

The complete speed/size builds exist for both compilers. Independent functional checks passed 38/38 before scoring. Raw reference [speed](reference/speed.json) and [size](reference/size.json), [source/compiler/binary freeze](freeze.json), [machine information](environment.json), [completion record](complete.json), and [protocol](../../performance/OFFICIAL.md) are retained.

The orchestration had two build-port failures and one size-JSON validation error. Failed attempts remain in sibling directories/logs. The size-only validation error happened after all four speed runs; speed results were not rerun, filtered or replaced. `frozen-driver.py` matches the pre-run driver hash; the corrected driver hash is recorded in `complete.json`.

Prior custom wall-clock findings remain [diagnostic only](../../PERFORMANCE.md). MiBench has no official suite aggregate identified in its distribution: no private aggregate is substituted for one. C3 will be evaluated with these same official scripts and workload settings.
