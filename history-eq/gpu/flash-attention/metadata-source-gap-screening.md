# FlashAttention fixed-sample metadata screen

All 170 source-gap candidates were screened from local commit messages and changed-path trees. Intent and checker scope are metadata classifications, not a Volta or Kuiper proof. Every target here lacks at least one exact historical changed source blob.

`UNKNOWN` means an NVIDIA kernel could potentially be compiled and compared if exact source were recovered. `UNSUPPORTED` means the performance change targets AMD, host/build code, or a multi-kernel scheduling relation outside Volta's selected one-PTX-kernel interface.

Reproduce with `git -C benchmarks/repos/flash-attention cat-file -p <commit>` and `git -C benchmarks/repos/flash-attention diff-tree --no-commit-id --name-only -r <commit>`.
