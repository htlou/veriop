# FlashAttention `8d454a3a`: SM100 tile scheduler fast division

The [archived historical diff](../source-screening/8d454a3a.source.diff) replaces two `Int32` divisions in `StaticPersistentTileScheduler.get_current_work` with `FastDivmod.divmod`. The same commit also enables an SM100 TMA output path, so scheduler arithmetic alone cannot establish whole-commit equivalence.

Run `alive2/.venv/bin/python history-eq/gpu/flash-attention/8d454a3a/check_scheduler.py` from the project root. The [result](scheduler-result.json) records `unsat` counterexample queries for each of 17 positive divisors (including 3, 5, 7, 12, 1000, and 2³¹−1), with every signed-nonnegative 32-bit dividend `0 ≤ x < 2³¹`. The query checks the source-derived `mul.hi.u32`/shift quotient against the old `x // divisor`; the remainder and both tile-coordinate divisions then follow from the same quotient formula. The script verifies its source-diff hash and the old/new expressions before checking.

Run `python3 -B history-eq/gpu/flash-attention/8d454a3a/check_kuiper_arithmetic.py` to recheck [the F* theorem](Kuiper.FlashAttention.FastDiv.fst) with Kuiper's bundled verifier. The [successful log](kuiper-arithmetic.log) and [source-locked result](kuiper-arithmetic-result.json) cover every mathematical `0 <= x < 2^31` and `1 < d < 2^31` when `k` satisfies `0 < k <= 31` and `2^(k-1) < d <= 2^k`. The theorem proves the source-formula quotient and remainder equal `x / d` and `x % d`, and that the multiplier and product fit their `u32`/`u64` carriers. The source's `d == 1` branch is covered by a separate trivial F* lemma.

**Verdict: partial, source-audited arithmetic equality.** This F* proof uses the verifier distributed with Kuiper; it is not a Kuiper proof of either CUDA kernel. The source-to-model mapping assumes that CuTe's `find_log2` returns that `k` and its `umulhi` implements unsigned high multiplication. The proof does not compare compiled PTX, generated scheduler code, TMA output behavior, or complete FlashAttention calls. No official before/after benchmark score is established for this historical commit.
