# llama.cpp `2dd84169`: AVX2 Q6_K dot product

The [exact historical diff](../source-screening/2dd84169.source.diff) changes the AVX2 branch of `ggml_vec_dot_q6_K_q8_K` in `ggml-cpu/arch/x86/quants.c`. The parent is `f454bd7eb8944629aabca163ea1c6e67e53fd77e`; the optimized commit is `2dd84169d1225c2a56ddd1902d718f4514d7536a`.

Run `python3 history-eq/gpu/llama.cpp/2dd84169/reproduce.py` from the project root. It archives each exact historical `ggml/` tree, compiles the complete original translation unit with Clang 20 using `-O2 -mavx2 -mfma`, and asks Alive2 to compare the changed function. Both [old](old.ll) and [new](new.ll) builds succeed. The [result record](alive2-result.json) saves commands, exit states, source/IR SHA-256 hashes, and checker output.

The installed Alive2 frontend rejects Clang's raw `noalias` and `nocapture` annotations. The script removes these attributes and LLVM metadata from [old](old.alive.ll) and [new](new.alive.ll) inputs, weakening assumptions on both sides without changing computation instructions. Both 45-second whole-function comparisons, old→new and new→old, reach Alive2's translation/analysis but hit the process timeout before a verdict.

The separate [nibble-unpack recheck](recheck_nibbles.py) extracts the exact old/new AVX2 expressions for `q4_0` through `q4_3` from the two historical source blobs. Eight Alive2 checks, forward and backward for each vector, prove equal outputs for arbitrary 256-bit input vectors ([result](nibble-result.json)). These checks do not include the new `bsums` relation, dot-product accumulation, floating-point output, or the full function. **Selected verdict: `EQUIV_PARTIAL`; whole-commit equivalence remains unverified.** No official benchmark result is inferred.

The unchanged historical `quantize_row_q8_K_ref` returns early for an all-zero input block after setting `d=0` and clearing `qs`, leaving `bsums` unwritten. The child dot product reads `bsums`; the parent does not. The [source-locked diagnostic](check_zero_bsums.py) builds both original translation units and calls the quantizer followed by the AVX2 dot product. Valgrind reports an uninitialized-value use for the child, while the parent and a child control that initializes `bsums` are clean ([record](zero-bsums-result.json)). All three native runs print zero output. The harness supplies only the needed historical fp16 table value, `0x3c00 → 1.0`; it does not build the entire ggml library. Valgrind's taint report is **not** a verified numerical counterexample or a complete language-semantics proof, so the full-function verdict remains unverified.
