# llama.cpp `930e2fa5`: Hexagon reshape copy

**Scoped verdict: `EQUIV_PARTIAL`.** The exact parent and child `DEFINE_CPY_RESHAPE` macro bodies from `cpy-ops.c` were instantiated for both FP32 and FP16. [Alive2 proves both directions in 16/16 checks](result.json): four fixed four-element layouts per type, covering a fully contiguous fast path, contiguous runs within padded rows, a run crossing a row boundary, and a strided scalar path. Each check takes arbitrary initialized input element bit patterns and compares all four destination elements; the row-boundary case initializes the two untouched elements to zero on both sides. The [source and IR hashes](result.json) and [reproduction script](reproduce.py) identify the precise scope.

The wrapper keeps the historical index-update loops and the historical `htp_tensor_is_contiguous` helper. It supplies exact division for the precomputed `fastdiv` divisors and models `hvx_copy_uu` as a nonoverlapping bytewise copy with the same visible writes as the source's predicated HVX store. Both local buffers are valid and separate. The extracted C is compiled with Clang 20 at `-O2`; only unsupported LLVM alias attributes and metadata are removed symmetrically before Alive2. The result is a proof of these eight source-mapped cases, **not** of the Hexagon intrinsics, arbitrary shapes, overlapping buffers, threading, or the full ggml copy operation.
