# fast_float `f4f36e04f7` — enable the four-digit fraction SWAR step on GCC

**Verdict: `EQUIV_PARTIAL` for the changed fraction step and its scalar fallback on little-endian x86.** The historical child `ascii_number.h` blob was missing locally. [recover.py](recover.py) reconstructs it from the exact parent file and the same preserved block in local HEAD; the reconstructed Git blob SHA-1 is **`6fa640db2144f283adf55c8a38f17f140956ee61`**, exactly the child tree's recorded object ID. [recovery.json](recovery.json) records both old and new object IDs. This is an exact-source recovery, not an approximate port.

On GCC, the parent preprocessor gate skips the four-digit SWAR step; the child runs it. [verify.py](verify.py) extracts the changed step and unchanged decimal fallback from those historical files. For a four-byte remainder and symbolic starting `uint64_t` value and input bytes, **bidirectional Alive2 passes** (`alive2-parse4*.log`). Alive2 times out for the analogous five-byte complete scanner (`alive2-parse5.log` and the separate `alive2-parse5-60s.log` retry), so a one-shot five-byte Alive2 proof is not claimed.

Three Z3 bit-vector checks prove the compositional step for **all four input bytes**: the SWAR digit guard accepts exactly four ASCII digits; its decoded value equals the scalar four-digit fold; and multiplying an arbitrary `uint64_t` prefix by 10,000 then adding that value equals four scalar iterations modulo 2⁶⁴ (`digit-guard.log`, `four-digit-value.log`, `uint64-fold.log`, all `unsat`). If fewer than four digits start the remainder, both versions enter the same unchanged scalar loop; otherwise the child consumes the same four digits and then enters that loop. The shared eight-digit loop is unchanged. This establishes the local scanner relation under stable readable input, but not a full public `from_chars` proof, all architectures, or all caller/error paths.

Run `python3 -B history-eq/c/fast_float/f4f36e04f7/verify.py` from the project root. No official historical before/after benchmark score was measured.
