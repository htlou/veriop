# XXH64 tail relation for `0e5dab97`

The historical change replaces XXH64's byte, four-byte, and eight-byte tail loops with `XXH64_finalize` and a switch on `len & 31`. [`reproduce.py`](reproduce.py) verifies the exact parent/child `xxhash.c` and `xxhash.h` Git blobs before compiling. It extracts the parent's one-shot and streaming tail bodies verbatim, calls the child's historical `XXH64_finalize`, and checks that the preceding one-shot and digest source tokens are identical after accounting for the relocated read macro, removed local tail pointers, and comments. The reset and update source regions are byte-identical.

**Result: 128/128 bidirectional Alive2 checks correct.** For each remainder 0–31, both one-shot and streaming wrappers take arbitrary input bytes, an arbitrary pre-tail `h64`, and an arbitrary number of preceding 32-byte blocks. The old wrapper processes that many tail bytes; the new wrapper passes `remainder + 32*blocks` to the historical finalizer. Clang 20 inlines both bodies; 56 of the 64 mode/remainder IR pairs differ. `--always-verify --fail-src-ub` reports no incorrect, failed-to-prove, or error result. A 32-byte, 8-byte-aligned by-value tail object makes all tested memory accesses and the parent's look-ahead pointer expressions valid. The [result](result.json) records source IDs, IR hashes, and each checker outcome.

This proves the tail transformation under the x86 little-endian, valid-buffer LLVM model for any incoming accumulator and any 32-byte-block count. Applying it to arbitrary one-shot lengths uses the source-audited fact that the shared prefix leaves a tail of `len % 32` bytes. For streaming digest, [the state check](check_stream_state.py) verifies the exact reset and update bodies are unchanged and proves the arithmetic invariant `memsize = total_len % 32`: both [SMT queries](stream_state.log) are unsatisfiable for an initialized state and any successful update length up to `PTRDIFF_MAX` on a 64-bit target, including `total_len` wraparound. The SMT transition treats each completed loop iteration as consuming 32 bytes; it does not establish pointer definedness, the loop-to-transition bridge, or all public state inputs. The separate [public one-shot check](../valid_blocks/README.md) verifies complete historical calls for every fixed length 0–255. The optimization-only table records `EQUIV_PARTIAL`; arbitrary-length whole-call and whole-commit equivalence remain unproved. No official historical benchmark score was measured.

Reproduce from the project root with `python3 history-eq/c/xxHash/0e5dab9/tail_lemma/reproduce.py` and `python3 history-eq/c/xxHash/0e5dab9/tail_lemma/check_stream_state.py`.
