# xxHash `3bb5bb6`: XXH32 tail and digest

**Verdict: `EQUIV_PARTIAL`.** This commit changes only `xxhash.c`. Besides introducing a switch-based XXH32 finalizer, it changes the main 16-byte loop bound and the endian-detection helper, so the digest proof below does not establish whole-commit equivalence.

[The initialized-state wrapper](wrap_digest_initialized.c) calls the exact historical `XXH32_digest_endian` with every state field initialized from symbolic scalar inputs. It checks each reachable `memsize` value `0..15` and both endian modes. [The Alive2 result](digest-initialized-all/result.json) proves **all 32 configurations bidirectionally**, with no remaining IR loops or loop-unroll bound. [The audit](digest-proof-audit.json) verifies the historical source object IDs, all IR/log hashes, and every result. This proves the digest calculation for initialized states on the tested x86-64 compilation; the scalar fields are otherwise arbitrary.

The initial pointer-state model ([result](digest-state-all/result.json)) proved 17 cases, timed out on others, and reported reverse-direction examples involving poison state bytes. The non-inlined run ([result](digest-state/result.json)) also treated the new helper call as unpaired. Neither is a validated counterexample on initialized states; the complete initialized-state check resolves this digest path. A [single `memsize=5, large_len=0` pointer-state retry](digest-split-one/result.json) timed out in both directions. The earlier fixed-length one-shot and streaming checks remain in their original artifacts. Whole one-shot and streaming equivalence, including the changed main-loop bound, is still unproved. No official historical before/after benchmark score was measured.
