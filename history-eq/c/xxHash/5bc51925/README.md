# xxHash `5bc51925`: streaming full-block consumption

**Verdict: `EQUIV_BOUNDED` for returned hashes at 2048 bytes.** The historical commit adds a full-block consumption path to `XXH3_update`. With the default secret, reset sets `nbStripesPerBlock` to 16, so a single 2048-byte update enters the new path (`2048 > 16 × 64`). The [source-locked reproduction](reproduce.py) compiles the exact parent and child `xxhash.h` blobs with Clang 20 `-O1`, `XXH_INLINE_ALL`, and public 64-bit/128-bit reset-update-digest wrappers. It checks that neither compared wrapper leaves a call to the public update function. [Alive2's four results](result.json) prove old→new and new→old returned-hash refinement for both widths with symbolic input bytes.

The LLVM comparison removes alias metadata and nonexecuting `noalias.scope.decl` annotations symmetrically because the installed Alive2 rejects them. This does not prove arbitrary input lengths, multiple update calls, caller-visible state fields, other configurations, or whole-library behavior. A previous wrapper attempt left `update` as a call and was discarded; the inlining guard in the reproduction prevents that false positive. No official historical before/after benchmark score is established here.
