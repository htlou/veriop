Run `python3 -B history-eq/c/xxHash/c5a6a14/check_declaration.py` from the project root. Its body and every caller are unchanged. The old `XXH_FORCE_INLINE` definitions all include `static`.

In ordinary implementation mode, both default and forced-hint configurations differ only in the internal `XXH64_finalize` declaration's inline/unused attributes; all executable expressions and function bodies are identical.
