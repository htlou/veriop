# s2n-bignum historical metadata screen

All 192 source-gap fixed-sample commits have changed-path trees. Seven have no local commit message: those cases use the pinned sample subject and changed paths; upstream pages were also reviewed for `002fdb01` and `799bfaea`. The other cases use local commit messages. Performance intent is metadata-screened, not an assembly proof. The 72 performance cases remain `UNKNOWN`: no before/after HOL Light relation was run for them. Upstream timing statements are intent evidence, not benchmark reruns here.

For the message-gap cases, [PR #318](https://github.com/awslabs/s2n-bignum/pull/318) provides the `002fdb01` benchmark context, and the [official `799bfaea` commit](https://github.com/awslabs/s2n-bignum/commit/799bfaea9af92a0b567cf3357ca6c889cbf7de53) describes replacing scalar ARM routines with NEON. The other five use the pinned subject and changed-path tree only.

Reproduce the metadata with `git -C benchmarks/repos/s2n-bignum show -s --format=%B <commit>` and `git -C benchmarks/repos/s2n-bignum diff-tree --no-commit-id --name-only -r <commit>`.
