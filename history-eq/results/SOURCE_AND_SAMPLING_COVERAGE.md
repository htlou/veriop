# Sampling and historical-source coverage

This audit distinguishes selected optimization-intent commits from actual checker runs. The initial draw is seeded within performance-keyword commits; later intent screens add some nonkeyword commits. Therefore these are reproducible samples, **not uniform random samples of every historical optimization**. A count below 200 means fewer optimizations have been identified in the screened population, not that the full repository has fewer than 200 optimizations.

`Marked not run` reproduces the sample ledger label. The source audit tests whether exact old/new **changed blobs** are present in the local Git stores with lazy fetching disabled. A present changed pair does not guarantee that unchanged dependencies or a supported checker are available.
