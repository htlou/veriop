The [audit](audit.py) verifies that this sampled optimization changes only `regex-syntax/src/hir/interval.rs`: parent Git blob `e063390a8ff59c3db1c47c4414440837769d7e9c`, optimized child `e3051bf3149cc60843f1c2c1b3d707b1d6a04a95`. The [optimized child file](interval.new.rs) was reconstructed by applying the [upstream commit patch](https://github.com/rust-lang/regex/commit/6d2b09ed6fbc136cca007ce0c57ec9cbae16f3b4.patch) to that exact parent blob; [the saved patch](upstream.patch) restores one context blank line omitted by the webpage renderer. `git hash-object` confirms both archived files have the expected blob IDs. Commit [`f082244`](https://github.com/rust-lang/regex/commit/f082244720d02fea04185c654e3d0dc95e39309d) changes the same one file back from that exact child blob to the exact parent blob. Its message cites three OSS-Fuzz reports.

**Scoped verdict: `NOT_EQUIV`.** The [native witness](witness.rs) compiles both exact historical modules against the same valid `u8` interval implementation. Starting with `[1,2]` and `[5,6]`, then pushing `[3,4]`, the parent returns `[1,6]` while the optimized child returns overlapping `[1,2]` and `[1,6]` from `intervals()`. After `negate`, the parent's set is `[0,0] ∪ [7,255]`; the child's is `[0,0] ∪ [0,3] ∪ [7,255]`. Byte `1` is absent in the parent and present in the child. The [reproduction](verify.sh) checks both Git blob IDs and repeats this result in debug and optimized Rust builds ([debug output](witness-debug.log), [release output](witness-release.log)). This refutes the generic interval-set operation sequence, including byte membership. It does not establish a complete historical crate build or an observed public regex-matching difference.

Charon extracted the two modules ([exit status](aeneas-status.log): 0), but [Aeneas stopped](aeneas.log) with exit status 1 at unsupported dependencies, including the parent's `canonicalize`; its partial Lean output is not a proof. The unequal verdict rests on the exact-source native counterexample, not Aeneas. No official historical before/after benchmark score was measured.
